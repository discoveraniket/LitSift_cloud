# Gemma 4 Direct Extraction Experiment

This standalone experiment tests Google Gemma 4 12B (`google/gemma-4-12b-qat`) running in LM Studio for direct scientific paper extraction without tool calling overhead.

## Setup & Execution

### 1. Ensure LM Studio is Running
- Open LM Studio.
- Load the model: `google/gemma-4-12b-qat`.
- Start the Local Server at `http://192.168.0.25:1234` (or `http://localhost:1234`).
- Ensure CORS is enabled.

### 2. Run the Benchmark
From the project root:
```bash
node experiments/gemma4_direct_extraction/run_gemma4_test.mjs
```

Or with custom parameters (if IP or model tag differs):
```bash
LMSTUDIO_URL="http://192.168.0.25:1234/v1" MODEL_NAME="google/gemma-4-12b-qat" node experiments/gemma4_direct_extraction/run_gemma4_test.mjs
```

### 3. Review the Output
The script will output a detailed analysis file:
`experiments/gemma4_direct_extraction/gemma4_extraction_report.txt`

The report includes:
1. **Telemetry**: Time to First Token (TTFT), tokens/sec throughput, total latency.
2. **Reasoning / Thinking**: Extracted thought process.
3. **Structured Table**: The Markdown data grid generated by Gemma 4.
4. **Verbatim Citation Audit**: Automated verification testing whether extracted quotes exist word-for-word in the source paper text.
